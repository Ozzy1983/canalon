# 🌍 Storm Gutter Company Website

A responsive website developed for a storm gutter installation company based in Barcelona, Spain. The site presents services, contact information, and company details in a clear and modern layout.

## 🔧 Technologies

- HTML, CSS, JavaScript

## 🚀 Run Locally

1. Clone the repository
2. Open `index.html` in your browser
